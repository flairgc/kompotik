# Пользовательский интерфейс Kompotik

Статус: проект для обсуждения, не описание реализованного приложения. Дата: 25 сентября 2026 года.

Основа: [архитектура v0.6](architecture.md), [функциональные требования](https://docs.google.com/document/d/13DhyOBaIGAJRgvpVTTC32wxpCtCYCFFowQn9RIn3KDU/edit) и [нефункциональные требования](https://docs.google.com/document/d/1c5UXA0RfIJ75Z2sQTfz0E-spPfpsIqhiP_baDNj83vI/edit). Более поздние уточнения из архитектуры имеют приоритет. Расположение элементов и новые детали сценариев ниже — предложения. Это схемы поведения без визуального дизайна.

Связанные документы: [API](api.md), [БД](database.md), [взаимодействие сервисов](service-interfaces.md).

Визуальные макеты: [Kompotik в Figma](https://www.figma.com/design/a0GtTMRpharBu8uacFwzWv). Актуальная для дальнейшей работы — светлая тема; тёмная временно архивирована до отдельного указания пользователя.

## 1. Карта экранов

```text
Вход / регистрация
         |
         +-- Главная
         |     +-- Повторение --> результат
         |
         +-- Папки и наборы
         |     +-- Языковой корень --> папка --> вложенная папка / набор --> карточка
         |     +-- Карточка --> другие значения / своя карточка
         |     +-- Первичное изучение --> результат
         |
         +-- Добавление слов
         |     +-- Готовая подборка --> добавить в набор
         |     +-- Свой текст --> анализ --> отбор --> добавить в набор
         |
         +-- Настройки и пользователь
               +-- Обучение / профиль / офлайн / синхронизация
```

В основном меню ровно четыре раздела. На телефоне предлагается нижняя навигация, на ПК — боковая. Урок открывается отдельным экраном. Язык обучения выбирается независимо от языка интерфейса; занятие всегда содержит один язык и один режим.

## 2. Вход и регистрация

```text
          Kompotik
Изучать слова — легко!
Email     [________________]
Пароль    [________________  глаз]
          [Войти]
          [Регистрация]
Ошибка: понятное сообщение рядом с формой
```

Уточнение пользователя от 27 сентября 2026 года: название `Kompotik` не переводится и на экране входа располагается по центру. Заголовок — «Изучать слова — легко!». Над формой нет переключателя «Вход / Регистрация»: переход «Регистрация» расположен ниже кнопки «Войти» и открывает отдельный экран создания аккаунта. Убраны надпись «СЛОВА ДЛЯ ВАШЕГО МИРА», поясняющий рекламный текст и постоянная подпись о подключении к интернету. Те же правила действуют при показе пароля.

Экран регистрации (уточнение пользователя от 27 сентября 2026 года):

```text
Регистрация
Email     [________________]
Пароль    [Придумайте пароль  глаз]
          [Создать аккаунт]
          [Вход]
```

Стрелки назад и переключателя «Вход / Регистрация» нет. Кнопка «Вход» под «Создать аккаунт» возвращает на экран входа. Вводный заголовок «Ваши первые слова начинаются здесь» и пояснение о доступных языках убраны.

Поле пароля — общий компонент с кнопкой-глазиком внутри справа. Когда пароль скрыт, показан закрытый глаз; когда виден — открытый. Нажатие переключает видимость без изменения введённого значения. Отдельной кнопки «Показать пароль» под полем нет. В пустом поле подсказка «Придумайте пароль» сохраняется при переключении. Компонент имеет обычное состояние, фокус и ошибку, каждое — со скрытым и видимым паролем; используется во входе, регистрации и при ошибке входа.

После регистрации создаются корни «Английский» и «Французский», открывается главная с пустой библиотекой и переходом к добавлению слов. Вход по внешним провайдерам отложен. Подтверждение почты и восстановление пароля требуют отдельного решения; кнопки не должны обещать неподдерживаемые сценарии.

Первый вход требует сети. Повторный офлайн-запуск открывает ранее загруженные материалы текущего аккаунта. Истёкшая серверная авторизация не удаляет локальный урок: перед отправкой результатов пользователь снова входит.

## 3. Главная

Уточнение пользователя от 27 сентября 2026 года: выбор языка обучения использует общий компонент «Выпадающий список». Текущее значение выровнено слева, отдельный шеврон вниз — справа. Компонент оформлен как поле с рамкой и имеет состояния «Обычное», «Фокус», «Недоступно». В светлых макетах он применяется во всех состояниях главной. Отдельный экран «Язык обучения» удалён по уточнению пользователя: выбор языка должен происходить через выпадающий список. Старые переходы к удалённому экрану в прототипе убраны; раскрытие списка пока не прототипировано.

```text
[Английский v]
Статистика: Английский
Выучено: 36 из 120 карточек
Период: [Неделя | Месяц]
Месяц: [предыдущий] Сентябрь 2026 [следующий]
Календарь: насыщенность заливки дня — количество выученных слов
Слайды: ○ ● ○  (Все языки / текущий язык / остальные языки)

Пора повторить: 12
  back — спина                    сегодня
  look up — искать в справочнике   вчера
  ...
[Повторять карточки]

Есть незавершённое занятие: [Продолжить]
Без сети · 2 результата ожидают отправки
```

Верхний заголовок «Главная» не показывается: после системной строки расположен выбор языка без пустого места под заголовок. Название раздела в нижней навигации сохраняется.

В карточке статистики сверху показано название языка или «Все языки», справа — переключатель «Неделя / Месяц». Ниже расположены подпись «карточек выучено» и крупное число прогресса. Между строками заголовка — компактные отступы 4 px.

Уточнение пользователя от 27 сентября 2026 года: кнопки «Этот язык / Все языки» заменены точками внизу карточки статистики. Это горизонтальный слайдер: первый слайд — «Все языки», второй — язык, выбранный в выпадающем списке сверху; второй слайд активен по умолчанию. Далее следуют остальные языки без дублирования текущего (например, французский при выбранном английском). Название охвата показано вверху карточки, над подписью «карточек выучено» и числом. Нажатие точки открывает соответствующий слайд; свайп вправо переходит к предыдущему слева, свайп влево — к следующему справа. На краях перехода по кругу нет. Смена языка в верхнем списке обновляет второй слайд и возвращает к нему. Перелистывание статистики не меняет выбранный язык обучения; период «Неделя / Месяц» и просматриваемый месяц сохраняются. В Figma связаны переходы по точкам; направление свайпов описывает поведение приложения.

Числа здесь иллюстративные. В статистике каждая карточка считается один раз независимо от числа наборов. Общий каталог вне личной библиотеки не входит в счётчики. Скрытый рейтинг и статистика ошибок не выводятся.

Уточнение пользователя от 27 сентября 2026 года: в карточке статистики справа сверху находится переключатель «Неделя / Месяц». Недельный вид — столбцы по дням; месячный — календарь с понедельника по воскресенье, в котором количество выученных за день слов отображается насыщенностью заливки. Надпись «СЛОВА, КОТОРЫЕ УЖЕ С ВАМИ» убрана. Шкала макета: 0, 1–3, 4–7, 8+ слов; это предлагаемые границы, а не утверждённые лимиты. Будущие дни приглушены и не считаются днями с нулевым результатом. Текущий день отмечен рамкой. В прототипе показаны сентябрь и август 2026 года с переходом между ними, оба периода доступны для текущего языка и для всех языков. Счётчик «36 из 120» отражает общий прогресс, а календарь — ежедневный; точные правила учёта повторного освоения карточки после сброса ещё требуют уточнения.

Кнопка запуска на главной называется «Повторять карточки», без количества в подписи. Пояснение «Начнём с 4 самых просроченных» не показывается.

Повторение выбирает наиболее просроченные карточки выбранного языка в пределах настройки 1–8. Если сроков нет, на обычной главной показано «На сегодня повторений нет»; новые карточки не подмешиваются. Отдельный экран «На сегодня всё» удалён по уточнению пользователя. Суммарный вид статистики не создаёт смешанный урок: язык запуска по-прежнему выбран явно.

Пустая библиотека: «Добавьте готовый набор или свой текст». При отсутствии сети доступны только подготовленные материалы. Неподтверждённые локальные результаты учитываются с пометкой; после синхронизации заменяются серверным состоянием без удвоения.

## 4. Папки и наборы

Отдельный экран «Действия с папкой» удалён: все действия доступны в контекстном меню папки. Создание папки, выбор назначения перемещения и подтверждение удаления открываются модально поверх текущей папки. Контекстное меню перед открытием модального окна закрывается; отмена возвращает к исходной папке. Переименование пока сохраняет отдельную форму с возвратом к меню.

### Модальные окна

Общий компонент — белая панель по центру затемнённого текущего экрана. Для макета шириной 390 px панель имеет ширину 350 px, внутренние отступы 24 px и скругление 20 px; затемнение — 36%. Высота зависит от содержимого. В шапке находятся заголовок и крестик закрытия, ниже — форма или плотный список, внизу — кнопки на ширину панели.

Создание папки показывает название и текущую папку назначения. Перемещение показывает доступные папки выбранного языка с выделением назначения. Подтверждение удаления явно перечисляет последствия и сохраняемые данные; безопасная кнопка «Оставить папку» отделена от красной «Удалить папку».

Крестик и «Отмена» закрывают окно без применения изменений. Затемнённый фон не закрывает форму при нажатии. Для реализации: фокус удерживается внутри окна, Escape отменяет действие, после закрытия фокус возвращается к вызвавшему элементу. При появлении клавиатуры панель размещается над ней; длинное содержимое прокручивается внутри при доступных заголовке и кнопках. В Figma настроены открытие оверлея, крестик, отмена и переход по подтверждению; ввод и изменения данных показаны состояниями макета.

В строке списка иконка папки или набора расположена слева, справа — отдельная кнопка More («⋯»). Нажатие строки открывает содержимое; нажатие More открывает контекстное меню именно этого элемента и не вызывает переход внутрь. Для папки доступны открытие, создание папки/набора, переименование, перемещение и удаление; для набора — открытие, добавление карточек, переименование, перемещение и удаление. Меню языкового корня содержит только открытие и создание папки/набора: переименование, перемещение и удаление системного корня недоступны.

На экране открытой папки или набора справа в заголовке находится кнопка More («⋯») с действиями текущего контейнера. «Создать папку» и «Создать набор» находятся в меню папки, включая языковой корень и пустую папку. Отдельных кнопок создания под списком и кнопки «Действия с папкой» нет. В пустой папке подсказка направляет к меню в заголовке. В меню набора доступны действия с набором и добавление карточек; создавать вложенные папки и наборы нельзя. Пункт «Открыть» в меню заголовка не нужен: контейнер уже открыт.

Списки языковых папок, вложенных папок и наборов используют компонент «Список строк»: единый блок со скруглением 12 px, без промежутков между строками, с разделителями 1 px. Строка имеет высоту от 64 px, отступы 12 px по вертикали и 16 px по горизонтали, название, дополнительную подпись и иконку. Вся строка нажимается; длинный текст переносится с увеличением высоты. В Figma предусмотрены варианты списка на 1–3 строки и состояния строки: обычное, нажатие, фокус и недоступность.

Заголовок общего корня библиотеки — «Мои наборы». Поиска языковых папок на этом экране нет: сразу показаны папки языков. Поиск содержимого внутри языковой папки сохраняется.

Уточнение пользователя от 27 сентября 2026 года: раздел «Папки» открывается общим корнем библиотеки со списком системных папок «Английский» и «Французский». Кнопок переключения языков в библиотеке нет. Нажатие на языковую папку открывает её содержимое; далее используется та же навигация по папкам и наборам. «Назад» поднимает на один уровень, из языковой папки — в общий корень. Создание папок и наборов доступно внутри языковой папки; в общем корне находятся только системные языковые папки. Выбор языка на главной остаётся отдельным элементом интерфейса.

```text
Папки и наборы
Английский /
  Книга /
    [Набор] Глава 1       8 из 12 выучено
    [Набор] Глава 2       0 из 15 выучено
  [Набор] Повседневное   6 из 30 выучено
Французский /
  [Набор] Первые слова   2 из 10 выучено
```

```text
Глава 1                                      [⋯]
Английский > Книга > Глава 1
[Изучать новые]
[Лупа: раскрыть / скрыть поиск]

  back — спина       На повторении     [открыть]
  look up — искать   Новая             [открыть]
  tree — дерево      Выучена           [открыть]
```

На экране набора поле поиска по умолчанию скрыто и раскрывается кнопкой с лупой справа от пути набора. Повторное нажатие скрывает поле. Карточки представлены компонентом «Список строк»: без промежутков, с разделителями и общей скруглённой оболочкой. Отдельные кнопки «Скачать», «Действия» и «Скрыть выученные» под прогрессом убраны. Скачивание доступно в меню набора; «Скрыть выученные» — независимый переключатель с чекбоксом в этом меню. Переключение фильтра обновляет список, меню остаётся открытым.

На макетах «Главы 1», включая варианты с поиском и фильтром, отдельные кнопки «Повторить» и «Добавить карточки» также убраны: над списком остаётся «Изучать новые».

Статусы отображаются словами: «Новая», «Изучается», «На повторении», «Выучена». Подготовка контента («Создаётся», «Ошибка подготовки») показывается отдельно от учебного прогресса. Незавершённая карточка не попадает в занятие.

Папка и набор — разные сущности. Экран папки показывает только вложенные папки и наборы, различимые по иконке и подписи типа; доступны «Создать папку» и «Создать набор». Карточки непосредственно в папку добавить нельзя. Экран набора показывает только карточки; действий создания вложенной папки или набора здесь нет. Обучение из набора использует его карточки; из папки — карточки всех наборов поддерева без дублей по ID. До первичного урока пользователь выбирает до своего лимита карточек со статусом `new` или `learning`. Для повторения выбор идёт по наступившему сроку.

Действия с папкой онлайн: создание, переименование, перемещение в пределах того же языкового корня, удаление. Корень нельзя удалить, переименовать как обычную папку или перенести. Предложение для удаления: подтверждение перечисляет вложенные папки и наборы и сообщает, что удаляются контейнеры и связи, а карточки и история обучения сохраняются. Для набора доступны создание в папке, переименование, перемещение в другую папку того же языка и удаление. В выборе назначения перемещения показываются только папки; набор не может быть родителем. Удаление ссылки на карточку из одного набора не затрагивает остальные.

Добавление карточек в набор открывает поиск доступных общих и собственных карточек выбранного языка. Можно отметить несколько и добавить ссылки на них; повторное добавление не создаёт дубликат. Создание собственной карточки доступно здесь же.

Пустая папка показывает «Нет папок и наборов» и кнопки «Создать папку» / «Создать набор». Пустой набор показывает «Нет карточек» с добавлением или созданием карточки. Пустые контейнеры не считаются изученными. Когда все карточки непустого набора выучены, показывается сообщение «Набор изучен — можно переходить к чтению или просмотру» с названием материала, если оно задано. Предлагается уведомление внутри приложения; push/email пока не определены. Новая неизученная карточка снимает завершённость набора.

## 5. Просмотр и создание карточки

```text
back                                      [назад]
спина · существительное
[изображение именно этого значения]
[слушать: британское] /bæk/ [другие варианты]
Статус: На повторении
[Я уже знаю] [Добавить в набор]

[Примеры и определение v]
[Грамматика и формы v]
[Другие значения v]       [Викисловарь]
[Создать свою карточку на этот смысл]
```

Из карточки `back = спина` можно открыть `back = назад`, но это другая карточка с отдельным прогрессом. Отдельный интерфейс синонимов не фиксируется до уточнения типов связей.

Для французского отображаются допустимые формы с артиклем и кнопки их озвучки. Несколько артиклей и диалектов не создают несколько карточек. Подпись аудио и транскрипция соответствуют выбранному варианту. Отсутствующие сведения скрываются или объясняются; британская озвучка не имитируется переименованием американской.

«Я уже знаю» действует на эту карточку во всех наборах. У выученной карточки доступно «Начать заново»; если она отмечена вручную, также понятно обозначена отмена этой отметки. Оба действия сбрасывают текущий цикл обучения, сохраняют историю и выполняются онлайн. Перед сбросом показывается краткое подтверждение его действия во всех наборах.

Общие карточки пользователь не редактирует. Форма своей карточки содержит язык, слово/выражение, выбранный смысл или новое определение, русский перевод, примеры и применимую грамматику. Язык задан корнем. При создании на существующий смысл он сохраняется, но карточка получает свой ID и отдельный прогресс.

```text
Своя карточка
Слово / выражение [________]
Значение         [________]
Перевод          [________]
Примеры, формы   [________]
Папка            [выбрана]
[Сохранить и подготовить]
        |
Черновик --> Подготовка картинки и аудио --> Готова
                      |
                 Ошибка [Повторить]
```

Черновик сохраняется при ошибке генерации. Изображение обязательно для готовности; обязательность готового аудио ещё открыта. Предложение: редактирование своей карточки создаёт новую ревизию; смена самого смысла требует новой карточки. Пока новая версия готовится, опубликованная остаётся доступна. Загрузка пользовательских картинок — будущее расширение, не действующая кнопка.

## 6. Добавление слов

### Готовые подборки

```text
Добавление слов                  [Английский v]
[Добавить свой текст]
Готовые наборы [поиск / уровень / цель]
  Лексика для книги ...   [Открыть]
  Уровень A1 ...          [Открыть]

Подборка: название, цель, состав, известные карточки
[Скрыть выученные] [Добавить набор]
Куда: Английский > ...      Название: [________]
```

Пользователь задаёт имя набора и выбирает папку. Состав копируется в личный набор, карточки остаются общими. Фильтр «Скрыть выученные» меняет просмотр; предложение — добавлять весь состав подборки, явно подписав это у кнопки. Изменения состава исходной подборки не меняют уже добавленный набор, обновления самих карточек приходят автоматически.

### Свой текст

```text
1. Материал
   Язык [Английский]  Название [Глава 1]
   Текст [_________________________________]
   [Анализировать]

2. Анализ
   «Определяем слова и выражения»
   [Можно уйти с экрана] [Отменить обработку]

3. Отбор
   [Выбрать всё] [Снять выбор] [Скрыть выученные]
   [x] look up — искать в справочнике   [контекст]
   [x] back — спина                    [другое значение]
   [ ] bank — требуется выбрать смысл  [разобрать]

4. Добавление
   [В новый набор | В существующий набор]
   Для нового набора: название и папка размещения
   Куда [Английский > Книга]  Название [Глава 1]
   [Добавить выбранные]
```

Базовый предлагаемый вход — вставленный текст. Кнопку загрузки файла добавляем только после согласования форматов и лимитов; загрузка ссылки или видео не обещается. Анализ ищет слова, формы и устойчивые выражения с конкретным значением, а не только уникальные строки.

Каждый кандидат показывает перевод/определение, контекст, найденную карточку, статус знания. Неоднозначный смысл пользователь выбирает из вариантов; при отсутствии подходящего подтверждает новый приватный смысл. Предложение: неподтверждённые неоднозначные кандидаты нельзя включить в окончательное добавление. Автоматическая оценка уверенности не показывается как достоверность в процентах.

Общая карточка переиспользуется, отсутствующая создаётся приватно и готовится в фоне. В наборе видны готовые карточки и состояния подготовки остальных. Начать можно с готовых. Ошибка одной генерации не уничтожает результат анализа или остальные карточки. Повтор подтверждения того же отбора не создаёт второй набор.

Список незавершённых импортов находится внутри «Добавления слов»: после закрытия приложения можно вернуться к анализу/отбору. Пустой результат предлагает изменить исходный текст. Отмена обработки — отдельное действие; уход с экрана её не отменяет.

## 7. Учебные экраны

```text
Английский · Изучение · 4 карточки         [Закрыть]
Знакомство: карточка 1 из 4
[слово, перевод, картинка, звук, подробности]
[Дальше]
        |
Задание 3 из 20
back · He hurt his back.
[спина] [дерево] [асфальт] [прыгать]
        |
Верный ответ / Ошибка: правильный ответ и пояснение
[Следующее задание]
        |
Занятие завершено
Изучено в этом занятии: 4 карточки
На повторение: ...
Результат сохранён [отправлен / ждёт подключения]
[Ещё подход] [Вернуться]
```

Первичное изучение: знакомство → прямой перевод с далёкими вариантами → с близкими → обратный перевод → аудирование → написание, если включено. Повторение не включает знакомство и далёкие варианты. Ошибка показывает решение и ведёт дальше, без бесконечных повторов.

| Упражнение | Что видит и делает пользователь |
| --- | --- |
| Прямой перевод | Иностранное слово и контекст, выбор русского значения. Контекст различает значения многозначного слова. |
| Обратный перевод | Русское значение с уточнением, выбор иностранного слова/выражения. |
| Аудирование | Кнопка воспроизведения с выбранным произношением, выбор значения; текст ответа заранее не раскрывается. |
| Написание | Перевод и контекст, ввод иностранного слова по буквам; регистр и допустимый артикль не влияют на оценку, диакритика влияет. |

Если нет однозначных вариантов ответа, тип задания заменяется допустимым по политике. Без скачанного аудио аудирование не начинается; перед уроком показано, какие упражнения доступны. Если для карточки нет ни одного упражнения, она не включается в урок с объяснением причины. Нельзя выдавать пропущенные упражнения за успешные.

После каждого ответа сохраняется локальный черновик. Закрытие или переключение языка оставляет его для продолжения на этом устройстве. Предложение: перед новым уроком того же языка пользователь продолжает или явно удаляет черновик. Полузавершённый урок не отправляет серверный прогресс. «Изучено в занятии» не означает статус «Выучена»: окончательное освоение требует повторений.

## 8. Настройки и пользователь

| Группа | Элементы |
| --- | --- |
| Пользователь | Email, выход, состояние авторизации. |
| Интерфейс | Русский/английский/французский; светлая/тёмная тема. |
| Обучение | 1–8 карточек за подход; написание включено/выключено; интервалы и период после ошибки. |
| Офлайн | Выбранные папки и наборы, размер, готовность, дата обновления, скачать/обновить/удалить локальную копию; дополнительные диалекты. |
| Синхронизация | Число ожидающих результатов, последняя успешная отправка, «Повторить отправку», ошибки, требующие входа или обновления. |

Изменения серверных настроек доступны онлайн и применяются к следующим урокам. Начатый урок сохраняет исходные правила. Численные значения по умолчанию берутся из версии учебной политики, а не вшиваются отдельно в интерфейс.

Удаление локальной копии не удаляет папку или набор на сервере. Материалы, нужные незавершённому уроку, удерживаются до его завершения/явного удаления. Выход с неотправленными результатами предлагает сначала синхронизировать; локальные данные другого аккаунта никогда не показываются. Детали защищённого сохранения очереди при выходе требуют реализации платформенного хранилища.

## 9. Общие состояния и взаимодействие

| Состояние | Поведение |
| --- | --- |
| Загрузка | Скелетон для чтения, индикатор выполнения для отправки. Повторное нажатие не дублирует операцию. |
| Ошибка чтения | Сообщение и повтор; ранее загруженный контент остаётся виден с отметкой. |
| Долгая обработка | Название этапа; проценты только при измеримом прогрессе. Можно вернуться позже. |
| Нет сети | Обучение по готовым локальным данным; создание, импорт и изменения недоступны с объяснением. |
| Кеш удалён браузером | Набор помечен неполным, предлагается повторное скачивание. |
| Конфликт версии | Загрузить актуальные данные и повторить осмысленное изменение; пользовательский ввод не теряется. |
| Устаревший клиент | Обновление с сохранением черновика и очереди; никаких перезагрузок посреди ответа. |

Предложение по клавиатуре: Tab/Enter для форм, 1–4 для вариантов ответа, Enter для продолжения после ответа, Escape для выхода с сохранением черновика. Горячие клавиши упражнений не перехватывают ввод в текстовом поле. На телефоне те же действия доступны кнопками.

## 10. Вопросы перед реализацией

Нужно определить форматы/размер текста, глубину ручной правки кандидатов, обязательность аудио для готовности, сценарии восстановления аккаунта и сроки офлайн-хранения. Расположение элементов, вид истории по дням и предложенные подтверждения можно уточнять без изменения основных сущностей и API.
