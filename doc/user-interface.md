# Пользовательский интерфейс Kompotik

Статус: проект для обсуждения, не описание реализованного приложения. Дата: 25 сентября 2026 года.

Основа: [архитектура v0.5](architecture.md), [функциональные требования](https://docs.google.com/document/d/13DhyOBaIGAJRgvpVTTC32wxpCtCYCFFowQn9RIn3KDU/edit) и [нефункциональные требования](https://docs.google.com/document/d/1c5UXA0RfIJ75Z2sQTfz0E-spPfpsIqhiP_baDNj83vI/edit). Более поздние уточнения из архитектуры имеют приоритет. Расположение элементов и новые детали сценариев ниже — предложения. Это схемы поведения без визуального дизайна.

Связанные документы: [API](api.md), [БД](database.md), [взаимодействие сервисов](service-interfaces.md).

## 1. Карта экранов

```text
Вход / регистрация
         |
         +-- Главная
         |     +-- Повторение --> результат
         |
         +-- Папки и карточки
         |     +-- Языковой корень --> папка --> вложенная папка
         |     +-- Карточка --> другие значения / своя карточка
         |     +-- Первичное изучение --> результат
         |
         +-- Добавление слов
         |     +-- Готовая подборка --> добавить в папки
         |     +-- Свой текст --> анализ --> отбор --> добавить в папки
         |
         +-- Настройки и пользователь
               +-- Обучение / профиль / офлайн / синхронизация
```

В основном меню ровно четыре раздела. На телефоне предлагается нижняя навигация, на ПК — боковая. Урок открывается отдельным экраном. Язык обучения выбирается независимо от языка интерфейса; занятие всегда содержит один язык и один режим.

## 2. Вход и регистрация

```text
Компотик
[ Вход | Регистрация ]
Email     [________________]
Пароль    [________________] [показать]
          [Войти / Создать аккаунт]
Ошибка: понятное сообщение рядом с формой
```

После регистрации создаются корни «Английский» и «Французский», открывается главная с пустой библиотекой и переходом к добавлению слов. Вход по внешним провайдерам отложен. Подтверждение почты и восстановление пароля требуют отдельного решения; кнопки не должны обещать неподдерживаемые сценарии.

Первый вход требует сети. Повторный офлайн-запуск открывает ранее загруженные материалы текущего аккаунта. Истёкшая серверная авторизация не удаляет локальный урок: перед отправкой результатов пользователь снова входит.

## 3. Главная

```text
Главная                       [Английский v]
Статистика: [этот язык | все языки]
Выучено: 36 из 120 карточек
История по дням: [календарь / простой график]

Пора повторить: 12
  back — спина                    сегодня
  look up — искать в справочнике   вчера
  ...
[Повторить 4 карточки]

Есть незавершённое занятие: [Продолжить]
Без сети · 2 результата ожидают отправки
```

Числа здесь иллюстративные. В статистике каждая карточка считается один раз независимо от числа папок. Общий каталог вне личной библиотеки не входит в счётчики. История показывает учебную активность по дням; скрытый рейтинг и статистика ошибок не выводятся.

Повторение выбирает наиболее просроченные карточки выбранного языка в пределах настройки 1–8. Если сроков нет, показано «На сегодня повторений нет»; новые карточки не подмешиваются. Суммарный вид статистики не создаёт смешанный урок: язык запуска по-прежнему выбран явно.

Пустая библиотека: «Добавьте готовый набор или свой текст». При отсутствии сети доступны только подготовленные материалы. Неподтверждённые локальные результаты учитываются с пометкой; после синхронизации заменяются серверным состоянием без удвоения.

## 4. Папки и карточки

```text
Папки и карточки
Английский /
  Книга /
    Глава 1 /       8 из 12 выучено
    Глава 2 /       0 из 15 выучено
  Повседневное /   6 из 30 выучено
Французский /
  Первые слова /   2 из 10 выучено
```

```text
Английский > Книга > Глава 1
[Изучать новые] [Повторить] [Скачать офлайн]
[Создать папку] [Добавить карточки] [Действия]
Поиск [________] [Скрыть выученные]

  back — спина       На повторении     [открыть]
  look up — искать   Новая             [открыть]
  tree — дерево      Выучена           [открыть]
```

Статусы отображаются словами: «Новая», «Изучается», «На повторении», «Выучена». Подготовка контента («Создаётся», «Ошибка подготовки») показывается отдельно от учебного прогресса. Незавершённая карточка не попадает в занятие.

Папка и набор — одна сущность. При запуске учитываются вложенные папки, дубли устраняются по ID карточки. До первичного урока пользователь выбирает до своего лимита карточек со статусом `new` или `learning`. Для повторения выбор идёт по наступившему сроку.

Действия с папкой онлайн: создание, переименование, перемещение в пределах того же языкового корня, удаление. Корень нельзя удалить, переименовать как обычную папку или перенести. Предложение для удаления: подтверждение перечисляет вложенные папки и сообщает, что удаляются связи с карточками, а не карточки и история обучения. Удаление ссылки на карточку из одной папки не затрагивает остальные.

Добавление карточек открывает поиск доступных общих и собственных карточек выбранного языка. Можно отметить несколько и добавить ссылки на них; повторное добавление не создаёт дубликат. Создание собственной карточки доступно здесь же.

Пустая папка имеет состояние «Нет карточек», а не «Всё изучено». Когда все уникальные карточки папки выучены, показывается сообщение «Набор изучен — можно переходить к чтению или просмотру» с названием материала, если оно задано. Предлагается уведомление внутри приложения; push/email пока не определены. Новая неизученная карточка снимает завершённость набора.

## 5. Просмотр и создание карточки

```text
back                                      [назад]
спина · существительное
[изображение именно этого значения]
[слушать: британское] /bæk/ [другие варианты]
Статус: На повторении
[Я уже знаю] [Добавить в папку]

[Примеры и определение v]
[Грамматика и формы v]
[Другие значения v]       [Викисловарь]
[Создать свою карточку на этот смысл]
```

Из карточки `back = спина` можно открыть `back = назад`, но это другая карточка с отдельным прогрессом. Отдельный интерфейс синонимов не фиксируется до уточнения типов связей.

Для французского отображаются допустимые формы с артиклем и кнопки их озвучки. Несколько артиклей и диалектов не создают несколько карточек. Подпись аудио и транскрипция соответствуют выбранному варианту. Отсутствующие сведения скрываются или объясняются; британская озвучка не имитируется переименованием американской.

«Я уже знаю» действует на эту карточку во всех папках. У выученной карточки доступно «Начать заново»; если она отмечена вручную, также понятно обозначена отмена этой отметки. Оба действия сбрасывают текущий цикл обучения, сохраняют историю и выполняются онлайн. Перед сбросом показывается краткое подтверждение его действия во всех папках.

Общие карточки пользователь не редактирует. Форма своей карточки содержит язык, слово/выражение, выбранный смысл или новое определение, русский перевод, примеры и применимую грамматику. Язык задан корнем. При создании на существующий смысл он сохраняется, но карточка получает свой ID и отдельный прогресс.

```text
Своя карточка
Слово / выражение [________]
Значение         [________]
Перевод          [________]
Примеры, формы   [________]
Папка            [выбрана]
[Сохранить и подготовить]
        |
Черновик --> Подготовка картинки и аудио --> Готова
                      |
                 Ошибка [Повторить]
```

Черновик сохраняется при ошибке генерации. Изображение обязательно для готовности; обязательность готового аудио ещё открыта. Предложение: редактирование своей карточки создаёт новую ревизию; смена самого смысла требует новой карточки. Пока новая версия готовится, опубликованная остаётся доступна. Загрузка пользовательских картинок — будущее расширение, не действующая кнопка.

## 6. Добавление слов

### Готовые подборки

```text
Добавление слов                  [Английский v]
[Добавить свой текст]
Готовые наборы [поиск / уровень / цель]
  Лексика для книги ...   [Открыть]
  Уровень A1 ...          [Открыть]

Подборка: название, цель, состав, известные карточки
[Скрыть выученные] [Добавить набор]
Куда: Английский > ...      Название: [________]
```

Состав копируется в личную папку, карточки остаются общими. Фильтр «Скрыть выученные» меняет просмотр; предложение — добавлять весь состав подборки, явно подписав это у кнопки. Изменения состава исходной подборки не меняют уже добавленную папку, обновления самих карточек приходят автоматически.

### Свой текст

```text
1. Материал
   Язык [Английский]  Название [Глава 1]
   Текст [_________________________________]
   [Анализировать]

2. Анализ
   «Определяем слова и выражения»
   [Можно уйти с экрана] [Отменить обработку]

3. Отбор
   [Выбрать всё] [Снять выбор] [Скрыть выученные]
   [x] look up — искать в справочнике   [контекст]
   [x] back — спина                    [другое значение]
   [ ] bank — требуется выбрать смысл  [разобрать]

4. Добавление
   [В новую папку | В существующую]
   Куда [Английский > Книга]  Название [Глава 1]
   [Добавить выбранные]
```

Базовый предлагаемый вход — вставленный текст. Кнопку загрузки файла добавляем только после согласования форматов и лимитов; загрузка ссылки или видео не обещается. Анализ ищет слова, формы и устойчивые выражения с конкретным значением, а не только уникальные строки.

Каждый кандидат показывает перевод/определение, контекст, найденную карточку, статус знания. Неоднозначный смысл пользователь выбирает из вариантов; при отсутствии подходящего подтверждает новый приватный смысл. Предложение: неподтверждённые неоднозначные кандидаты нельзя включить в окончательное добавление. Автоматическая оценка уверенности не показывается как достоверность в процентах.

Общая карточка переиспользуется, отсутствующая создаётся приватно и готовится в фоне. В папке видны готовые карточки и состояния подготовки остальных. Начать можно с готовых. Ошибка одной генерации не уничтожает результат анализа или остальные карточки. Повтор подтверждения того же отбора не создаёт вторую папку.

Список незавершённых импортов находится внутри «Добавления слов»: после закрытия приложения можно вернуться к анализу/отбору. Пустой результат предлагает изменить исходный текст. Отмена обработки — отдельное действие; уход с экрана её не отменяет.

## 7. Учебные экраны

```text
Английский · Изучение · 4 карточки         [Закрыть]
Знакомство: карточка 1 из 4
[слово, перевод, картинка, звук, подробности]
[Дальше]
        |
Задание 3 из 20
back · He hurt his back.
[спина] [дерево] [асфальт] [прыгать]
        |
Верный ответ / Ошибка: правильный ответ и пояснение
[Следующее задание]
        |
Занятие завершено
Изучено в этом занятии: 4 карточки
На повторение: ...
Результат сохранён [отправлен / ждёт подключения]
[Ещё подход] [Вернуться]
```

Первичное изучение: знакомство → прямой перевод с далёкими вариантами → с близкими → обратный перевод → аудирование → написание, если включено. Повторение не включает знакомство и далёкие варианты. Ошибка показывает решение и ведёт дальше, без бесконечных повторов.

| Упражнение | Что видит и делает пользователь |
| --- | --- |
| Прямой перевод | Иностранное слово и контекст, выбор русского значения. Контекст различает значения многозначного слова. |
| Обратный перевод | Русское значение с уточнением, выбор иностранного слова/выражения. |
| Аудирование | Кнопка воспроизведения с выбранным произношением, выбор значения; текст ответа заранее не раскрывается. |
| Написание | Перевод и контекст, ввод иностранного слова по буквам; регистр и допустимый артикль не влияют на оценку, диакритика влияет. |

Если нет однозначных вариантов ответа, тип задания заменяется допустимым по политике. Без скачанного аудио аудирование не начинается; перед уроком показано, какие упражнения доступны. Если для карточки нет ни одного упражнения, она не включается в урок с объяснением причины. Нельзя выдавать пропущенные упражнения за успешные.

После каждого ответа сохраняется локальный черновик. Закрытие или переключение языка оставляет его для продолжения на этом устройстве. Предложение: перед новым уроком того же языка пользователь продолжает или явно удаляет черновик. Полузавершённый урок не отправляет серверный прогресс. «Изучено в занятии» не означает статус «Выучена»: окончательное освоение требует повторений.

## 8. Настройки и пользователь

| Группа | Элементы |
| --- | --- |
| Пользователь | Email, выход, состояние авторизации. |
| Интерфейс | Русский/английский/французский; светлая/тёмная тема. |
| Обучение | 1–8 карточек за подход; написание включено/выключено; интервалы и период после ошибки. |
| Офлайн | Выбранные папки, размер, готовность, дата обновления, скачать/обновить/удалить локальную копию; дополнительные диалекты. |
| Синхронизация | Число ожидающих результатов, последняя успешная отправка, «Повторить отправку», ошибки, требующие входа или обновления. |

Изменения серверных настроек доступны онлайн и применяются к следующим урокам. Начатый урок сохраняет исходные правила. Численные значения по умолчанию берутся из версии учебной политики, а не вшиваются отдельно в интерфейс.

Удаление локальной копии не удаляет папку на сервере. Материалы, нужные незавершённому уроку, удерживаются до его завершения/явного удаления. Выход с неотправленными результатами предлагает сначала синхронизировать; локальные данные другого аккаунта никогда не показываются. Детали защищённого сохранения очереди при выходе требуют реализации платформенного хранилища.

## 9. Общие состояния и взаимодействие

| Состояние | Поведение |
| --- | --- |
| Загрузка | Скелетон для чтения, индикатор выполнения для отправки. Повторное нажатие не дублирует операцию. |
| Ошибка чтения | Сообщение и повтор; ранее загруженный контент остаётся виден с отметкой. |
| Долгая обработка | Название этапа; проценты только при измеримом прогрессе. Можно вернуться позже. |
| Нет сети | Обучение по готовым локальным данным; создание, импорт и изменения недоступны с объяснением. |
| Кеш удалён браузером | Набор помечен неполным, предлагается повторное скачивание. |
| Конфликт версии | Загрузить актуальные данные и повторить осмысленное изменение; пользовательский ввод не теряется. |
| Устаревший клиент | Обновление с сохранением черновика и очереди; никаких перезагрузок посреди ответа. |

Предложение по клавиатуре: Tab/Enter для форм, 1–4 для вариантов ответа, Enter для продолжения после ответа, Escape для выхода с сохранением черновика. Горячие клавиши упражнений не перехватывают ввод в текстовом поле. На телефоне те же действия доступны кнопками.

## 10. Вопросы перед реализацией

Нужно определить форматы/размер текста, глубину ручной правки кандидатов, обязательность аудио для готовности, сценарии восстановления аккаунта и сроки офлайн-хранения. Расположение элементов, вид истории по дням и предложенные подтверждения можно уточнять без изменения основных сущностей и API.
