# Термины Kompotik

Термин «значение слова» (`WordSense`) утверждён владельцем проекта 26 сентября 2026 года и используется в документации, коде, названиях таблиц и методов.

## Значение слова — WordSense

**Значение слова (WordSense)** — слово в одном конкретном смысле, с которым связаны соответствующие этому смыслу переводы, изображения и языковые данные, включая морфологию. Для поддерживаемых приложением многословных выражений используется тот же термин.

Например, «лук» как растение и «лук» как оружие — разные значения слова: у них разные переводы (`onion` и `bow`) и изображения. Одинаковое написание или перевод сами по себе не означают совпадение значений.

## Связанные понятия

- **Папка (`Folder`)** — контейнер для вложенных папок и наборов карточек. Непосредственно карточки в папке не размещаются.
- **Набор карточек (`CardSet`)** — отдельная сущность внутри папки, содержащая только карточки. Вложенные наборы и папки в наборе запрещены. Одна карточка может входить в несколько наборов; прогресс общий для пары пользователь/карточка.
- **Языковой корень** — системная папка языка. Папки, наборы и их карточки относятся к языку этого корня. Пример: Английский → папка «Книга» → набор «Глава 1» → карточки.
- **Лексическая единица (`LexicalEntry`)** — слово или выражение на определённом языке. С ней могут быть связаны несколько значений слова; омонимы могут относиться к разным лексическим единицам.
- **Значение слова (`WordSense`)** — конкретный смысл этой лексической единицы.
- **Карточка (`Card`)** — учебное представление значения слова: перевод, определение, примеры, морфология, изображение и аудио. Карточка ссылается на `WordSense`; её содержимое хранится в ревизиях карточки. Одно значение может иметь общую и приватные карточки согласно правилам архитектуры. Прогресс остаётся связан с карточкой.

Связь данных со значением не требует хранить их все в одной таблице. Общая для нескольких значений морфология может относиться к лексической единице; конкретное хранение определяется схемой данных.

## Именование

Разделение папки и набора утверждено владельцем 27 сентября 2026 года и заменяет прежнюю модель «папка = набор». В проектных контрактах набор называется `CardSet`, таблицы — `card_sets` и `card_set_cards`, идентификатор — `card_set_id`, группа API — `/card-sets`. Конкретные поля и методы остаются проектными предложениями.

| Контекст | Название |
| --- | --- |
| Термин в документации | значение слова |
| Тип или сущность | `WordSense` |
| Переменная / список | `wordSense` / `wordSenses` |
| Идентификатор в коде | `wordSenseId` |
| Таблица | `word_senses` |
| Внешний ключ в БД / поле API в snake_case | `word_sense_id` |
| Примеры методов | `getWordSense()`, `createWordSense()` |

В проектных схемах прежние `Sense`, `senses` и `sense_id` заменены на `WordSense`, `word_senses` и `word_sense_id`. Слово «смысл» в поясняющем тексте обозначает конкретное значение слова, а не отдельную сущность. `external_sense_id` сохраняет имя идентификатора значения во внешнем словарном источнике.
